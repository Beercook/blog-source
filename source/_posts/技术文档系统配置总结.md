## 🎯 如何使用

### 创建新文档的步骤：

1. **创建文档**
   ```bash
   hexo new "文档标题"
   ```

2. **编辑文档**
   在文件开头添加 Front-matter：
   ```yaml
   ---
   title: 文档标题
   date: 2026-04-29 12:00:00
   categories:
     - 技术文档
     - 子分类（可选）
   tags:
     - 标签1
     - 标签2
   ---
   ```

3. **编写内容**
   使用 Markdown 语法编写文档内容

4. **部署**
   ```bash
   .\deploy.bat
   ```

## 💡 最佳实践

1. **每个文档必须有分类**
   - 至少包含"技术文档"主分类
   - 可以添加更细的子分类

2. **添加相关标签**
   - 使用 2-5 个标签
   - 标签应该能概括文档核心技术点

3. **使用清晰的标题**
   - 让人一眼看出文档主题
   - 避免过于宽泛的标题

4. **规范日期格式**
   - 使用 `YYYY-MM-DD HH:MM:SS` 格式
   - 保持时间顺序

5. **代码块标注语言**
   ```markdown
   ```javascript
   // 代码内容
   ```
   ```
