## 🎯 如何上传你的笔记文档

### 三步快速上手

#### 第 1 步：创建文档
```bash
hexo new "你的文档标题"
```

#### 第 2 步：编辑文档
在 `source/_posts/` 目录下找到刚创建的 `.md` 文件，添加以下内容：

```markdown
---
title: 你的文档标题
date: 2026-04-30 12:00:00
categories:
  - 技术文档
  - 笔记文档    ← 重要：设置为"笔记文档"
tags:
  - 标签1
  - 标签2
---

# 你的文档标题

这里是你的笔记内容...
```

#### 第 3 步：部署
```bash
.\deploy.bat
```

## 💡 关键要点

### ✅ 必须做的
1. **设置正确的分类**：
   ```yaml
   categories:
     - 技术文档
     - 笔记文档    ← 你自己的文档必须用这个
   ```

2. **添加相关标签**：
   ```yaml
   tags:
     - Vue.js
     - JavaScript
   ```

3. **使用规范的日期格式**：
   ```yaml
   date: 2026-04-30 14:00:00
   ```

### ❌ 不要做的
1. 不要将你的文档归类到"网站文档"（那是助手生成的文档）
2. 不要忘记添加分类和标签
3. 不要忘记执行部署命令
