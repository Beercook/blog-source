### 3. 修复黑胶唱片封面更新问题

**问题描述**：
黑胶唱片中心的封面图片无法随歌曲切换而更新，始终显示默认渐变背景。

**根本原因**：
CSS中的`.disc-cover`元素有默认的渐变背景：
```css
.disc-cover {
    background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
}
```

JavaScript设置`backgroundImage`时，这个默认背景未被清除，导致封面图片被覆盖。

**解决方案**：
在`loadSong()`函数中，设置封面前先清除所有背景样式：

```javascript
if (this.discCoverEl) {
    // 先清除所有背景相关样式
    this.discCoverEl.style.background = 'none';
    this.discCoverEl.style.backgroundColor = 'transparent';
    // 然后设置背景图片
    this.discCoverEl.style.backgroundImage = `url('${song.cover}')`;
    this.discCoverEl.style.backgroundSize = 'cover';
    this.discCoverEl.style.backgroundPosition = 'center';
    this.discCoverEl.style.backgroundRepeat = 'no-repeat';
    console.log('封面已更新为:', song.cover);
}
```

**修改文件**：`source/js/music-player.js`

## 二、操作步骤总结

### 完整部署流程

#### 步骤1：准备音乐文件
将新歌曲的三个文件放入对应目录：
```
source/music/
├── audio/      # 音频文件 (.mp3)
├── covers/     # 封面图片 (.jpg/.png)
└── lrc/        # 歌词文件 (.lrc)
```

#### 步骤2：更新配置文件

**A. 编辑 `source/music/index.md`**
在播放列表部分（playlist-grid）添加新的歌曲项：

```html
<div class="playlist-item" onclick="playSong(this, '歌曲名', '歌手')">
    <div class="playlist-cover" style="background-image: url('/music/covers/封面文件名'); background-size: cover; background-position: center;"></div>
    <div class="playlist-info">
        <div class="playlist-title-text">歌曲名</div>
        <div class="playlist-artist">歌手</div>
    </div>
    <div class="playlist-duration">时长</div>
</div>
```

同时更新歌曲数量：
```html
<span class="playlist-count">X首</span>
```

**B. 编辑 `source/js/music-player.js`**
在`songs`数组中添加歌曲配置：

```javascript
{
    title: '歌曲名',
    artist: '歌手',
    url: '/music/audio/音频文件名.mp3',
    cover: '/music/covers/封面文件名.jpg',
    lrc: '/music/lrc/歌词文件名.lrc',
    duration: '时长'
}
```

#### 步骤3：清理并生成
```bash
cd e:\jdyblog\jdyblog
hexo clean
hexo generate
```

#### 步骤4：验证生成结果
检查生成的文件是否正确：
```powershell
# 检查歌曲数量
(Get-Content public\music\index.html -Encoding UTF8 | Select-String "playlist-count").Line

# 检查新歌是否出现
(Get-Content public\music\index.html -Encoding UTF8 | Select-String "新歌名").Count
```

#### 步骤5：部署到服务器
```bash
hexo deploy
```

#### 步骤6：提交到Git仓库
```bash
git add -A
git commit -m "提交说明"
git push
```

#### 步骤7：更新版本标签
```bash
# 删除旧标签（如果存在）
git tag -d "标签名"

# 创建新标签
git tag -a "标签名" -m "标签说明"

# 推送标签到远程
git push origin :refs/tags/标签名
git push origin 标签名
```

## 四、如何添加新音乐

### 方法一：手动添加（推荐）

#### 第1步：准备文件
准备好三个文件：
- 音频文件：`歌曲名.mp3`
- 封面图片：`歌曲名.jpg` 或 `歌曲名.png`
- 歌词文件：`歌曲名.lrc`

#### 第2步：上传文件
将文件放入对应目录：
```
source/music/audio/歌曲名.mp3
source/music/covers/歌曲名.jpg
source/music/lrc/歌曲名.lrc
```

#### 第3步：编辑 index.md
打开 `source/music/index.md`，找到播放列表部分（搜索 `playlist-grid`），在最后一个 `playlist-item` 后添加：

```html
<div class="playlist-item" onclick="playSong(this, '歌曲名', '歌手名')">
    <div class="playlist-cover" style="background-image: url('/music/covers/歌曲名.jpg'); background-size: cover; background-position: center;"></div>
    <div class="playlist-info">
        <div class="playlist-title-text">歌曲名</div>
        <div class="playlist-artist">歌手名</div>
    </div>
    <div class="playlist-duration">4:30</div>
</div>
```

同时更新歌曲数量（搜索 `playlist-count`）：
```html
<span class="playlist-count">11首</span>  <!-- 原来是10首，现在是11首 -->
```

#### 第4步：编辑 music-player.js
打开 `source/js/music-player.js`，找到 `songs` 数组，在最后一个歌曲对象后添加：

```javascript
{
    title: '歌曲名',
    artist: '歌手名',
    url: '/music/audio/歌曲名.mp3',
    cover: '/music/covers/歌曲名.jpg',
    lrc: '/music/lrc/歌曲名.lrc',
    duration: '4:30'
},
```

注意：最后一个对象后面不要加逗号，其他对象后面都要加逗号。

#### 第5步：部署
```bash
cd e:\jdyblog\jdyblog
hexo clean
hexo generate
hexo deploy
git add -A
git commit -m "添加新歌曲：歌曲名"
git push
```

### 方法二：批量添加
如果要添加多首歌曲，建议：
1. 先准备好所有文件
2. 一次性编辑 `index.md` 添加所有播放列表项
3. 一次性编辑 `music-player.js` 添加所有歌曲配置
4. 统一部署

## 六、常见问题解决

### 问题1：添加歌曲后不显示
**原因**：可能修改了 `index.html` 而不是 `index.md`
**解决**：确保修改的是 `source/music/index.md` 文件

### 问题2：封面不更新
**原因**：CSS默认背景覆盖了JavaScript设置的背景图片
**解决**：已在 `music-player.js` 中修复，确保使用最新的代码

### 问题3：浏览器缓存
**症状**：部署后访问网站仍显示旧版本
**解决**：按 `Ctrl + F5` 强制刷新，或清除浏览器缓存

### 问题4：中文乱码
**原因**：文件编码问题
**解决**：确保所有文件使用UTF-8编码

### 问题5：歌曲无法播放
**检查清单**：
- 音频文件路径是否正确
- 文件格式是否为MP3
- 文件是否成功上传到服务器
- 浏览器控制台是否有错误信息

## 九、技术要点总结

### 1. Hexo文件优先级
- `.md` 文件优先于 `.html` 文件
- 同时存在时会处理 `.md` 文件
- 这是本次优化中发现的关键问题

### 2. CSS背景优先级
- inline style（JavaScript设置）会被CSS中的默认值影响
- 需要先清除默认背景再设置新背景
- 使用 `background = 'none'` 可以清除所有背景相关属性

### 3. 部署流程规范
- 必须先 `hexo clean` 清除缓存
- 然后 `hexo generate` 生成静态文件
- 最后 `hexo deploy` 部署到服务器
- 记得提交源代码到Git仓库

### 4. 版本管理
- 每次重大更改创建Git标签
- 标签命名规范：`v版本号-简短描述`
- 标签推送到远程仓库
