# 笔记文档使用说明

## 📚 文档分类说明

本博客的技术文档分为两个子分类：

### 1. 网站文档
- **用途**：存放由助手生成的所有配置、部署、使用指南等文档
- **包含内容**：Hexo 配置、部署指南、Git 命令、主题设置等
- **当前文档数**：8 篇

### 2. 笔记文档
- **用途**：存放你自己上传的个人学习笔记和技术文章
- **包含内容**：你的个人学习记录、项目笔记、技术总结等
- **当前文档数**：0 篇（等待你添加）

---

## 📝 如何上传自己的笔记文档

### 方法一：命令行创建（推荐）

#### 步骤 1：创建新文档
```bash
hexo new "你的文档标题"
```

例如：
```bash
hexo new "Vue.js 学习笔记"
hexo new "Python 数据分析入门"
hexo new "Docker 容器化实践"
```

#### 步骤 2：编辑文档
在 `source/_posts/` 目录下找到刚创建的 `.md` 文件，用你喜欢的编辑器打开。

#### 步骤 3：添加 Front-matter
在文件开头添加以下信息（**重要：将分类改为"笔记文档"**）：

```markdown
---
title: 你的文档标题
date: 2026-04-30 12:00:00
categories:
  - 技术文档
  - 笔记文档
tags:
  - 标签1
  - 标签2
---

# 你的文档标题

这里是你的笔记内容...
```

#### 步骤 4：编写内容
使用 Markdown 语法编写你的笔记内容。

#### 步骤 5：预览效果（可选）
```bash
hexo server -p 80
```
访问 http://localhost/ 查看效果。

#### 步骤 6：部署到服务器
```bash
.\deploy.bat
```

---

### 方法二：手动创建文件

#### 步骤 1：创建文件
在 `source/_posts/` 目录下创建一个新的 `.md` 文件，例如：
- `Vue学习笔记.md`
- `Python数据分析.md`
- `项目总结.md`

#### 步骤 2：添加 Front-matter
在文件开头添加：

```markdown
---
title: 文档标题
date: 2026-04-30 12:00:00
categories:
  - 技术文档
  - 笔记文档
tags:
  - 相关标签
---
```

#### 步骤 3：编写内容并部署
同上。

## 💡 最佳实践

### 1. 分类规范
- **必须**包含主分类：`技术文档`
- **必须**包含子分类：`笔记文档`（你自己的文档）
- 可以添加更多细分分类（可选）

### 2. 标签建议
- 使用 2-5 个标签
- 标签应该能概括文档的核心技术点
- 常用标签示例：JavaScript, Python, Vue.js, React, Node.js, 数据库, Docker 等

### 3. 标题规范
- 使用清晰的标题
- 让人一眼看出文档主题
- 避免过于宽泛的标题

### 4. 日期格式
- 使用 `YYYY-MM-DD HH:MM:SS` 格式
- 保持时间顺序

### 5. 内容组织
- 使用 Markdown 语法
- 添加目录（长文档）
- 代码块标注语言类型
- 使用 `<!-- more -->` 设置摘要

## 🔍 查看你的笔记

上传文档后，你可以通过以下方式查看：

### 1. 按分类浏览
访问：http://localhost/categories/
- 点击"技术文档" → "笔记文档"
- 查看你上传的所有笔记

### 2. 按标签浏览
访问：http://localhost/tags/
- 通过标签云查找相关笔记

### 3. 搜索功能
使用博客内置搜索功能，输入关键词查找笔记
