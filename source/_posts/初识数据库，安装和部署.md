#  数据库程序安装部署MySQL

## 步骤一：数据库部署环境准备

```bash
数据库程序安装部署MySQL
步骤一：数据库部署环境准备
- 系统环境准备：麒麟 V10 sp3 / CentOS 7.9
- 系统基础优化：
	关闭防火墙：systemctl stop firewalld / systemctl disable firewalld
	关闭selinux：
	setenforce 0			#	临时生效    
	vi /etc/selinux/config	#	永久生效
	第七行SELINUX=disabled

	设置完成后reboot重启，然后getenforce检查状态，看看是否显示disable
	[root@mysql3 ~]# getenforce
	Disabled

	卸载已有数据库：
	先检查是否已有数据库程序包，以免后续安装mariadb冲突
[root@mysql ~]#rpm -qa |grep mariadb
mariadb-connector-c-3.0.6-8.ky10.x86_64
#	这个无所谓，但如果有别的就完犊子，就得卸载，像只有maraidb-加版本号: command not found
[root@mysql ~]#rpm -qa |grep mysql


	如果有，删除已有数据库
[root@mysql ~]#yum remove -y `rpm -qa | grep mariadb`
或者用
[root@mysql ~]# rpm -e `rpm -qa|grep mysql` --nodeps
```

## 步骤二：数据库程序下载安装（采用二进制方式安装）

```bash
步骤二：数据库程序下载安装（采用二进制方式安装） 
下载数据库程序二进制包：
https://downloads.mysql.com/archives/get/p/23/file/mysql-8.0.36-linux-glibc2.12-x86_64.tar.xz

安装数据库二进制的程序⭐：
1.cd /usr/local/

2.上传mysql的安装包
#	在centos系统中上传时，需要解决安装源问题，要更换新的安装源，然后安装lrzsz，才能上传压缩包
第一步：备份当前的 yum 配置
mv /etc/yum.repos.d/CentOS-Base.repo /etc/yum.repos.d/CentOS-Base.repo.backup
第二步：下载阿里云的 CentOS 7 repo 文件(如果 curl 或 wget 也用不了，请看下方的“特殊情况”【特殊情况已省略，如出错，问AI去】)
curl -o /etc/yum.repos.d/CentOS-Base.repo https://mirrors.aliyun.com/repo/Centos-7.repo
如果提示 curl: command not found，尝试用 wget：
wget -O /etc/yum.repos.d/CentOS-Base.repo https://mirrors.aliyun.com/repo/Centos-7.repo
第三步：清理并生成新的缓存
yum clean all
yum makecache
第四步：再次安装 lrzsz
yum -y install lrzsz

3.tar xf mysql-8.0.36-linux-glibc2.12-x86_64.tar.xz		#	解压安装包
4.ln -s mysql-8.0.36-linux-glibc2.12-x86_64  mysql		#	做一个软连接
5.vim /etc/profile
export PATH="$PATH:/usr/local/mysql/bin"
6.source /etc/profile
7.mysql -V
显示：mysql  Ver 8.0.36 for Linux on x86_64 (MySQL Community Server - GPL)
```

## 步骤四：编辑数据库服务配置文件

```bash
编辑数据库配置文件作用：可以设置数据库服务功能/实现数据库运行启动
cat >/etc/my.cnf <<EOF
[mysqld]
port=3306
user=mysql
datadir=/data/3306/data
basedir=/usr/local/mysql
socket=/tmp/mysql.sock
EOF
```

### 3）数据库服务权限管理

```bash
show privileges；
-- 显示数据库所有权限信息
MySQL数据库常用权限信息
Alter        -- 可以修改数据表信息
Create       -- 可以创建数据库和数据表
Create view  -- 可以具有创建数据视图能力 ？？？（连表查询数据）
Create user  -- 创建数据库新用户能力   
Delete       -- 删除表中数据权限（业务用户需要的权限）
```

# 总结

```sh
01 数据库编译安装部署步骤流程############################################################# 
①环境准备：
	关闭防火墙 (firewalld) 和 SELinux。
	卸载冲突的旧版本数据库（如 mariadb）。
	配置YUM源并安装上传工具 (lrzsz)。
②程序下载与安装：
	下载二进制压缩包并解压到 /usr/local/。
	创建软连接 (ln -s) 指向新版本目录。
	配置环境变量：将 /usr/local/mysql/bin 加入 /etc/profile 并生效 (source)。
③数据库初始化 (核心步骤)：
	创建数据目录 (/data/3306/data) 和 mysql 用户，并授权。
	执行初始化命令：
		不安全初始化 (免密登录): mysqld --initialize-insecure ...
		安全初始化 (生成临时密码): mysqld --initialize ...
		注意：若初始化失败，需清空数据目录后重试。
④配置文件编写：
	创建 /etc/my.cnf，配置端口、用户、数据目录 (datadir)、基于目录 (basedir) 和 socket 路径。
⑤启动服务：
	复制启动脚本 /usr/local/mysql/support-files/mysql.server 到 /etc/init.d/mysqld。
	使用 /etc/init.d/mysqld start 或 systemctl (需配置service文件) 启动。
	验证端口监听 (netstat -ntulp) 并登录测试。

02 数据库服务架构体系架构组成############################################################# 
MySQL 架构可简略概括为四层结构：

1.连接层：负责客户端连接、身份认证和权限校验。
2.服务层（核心）：负责 SQL 解析、优化（生成执行计划）和查询执行，包含内置函数和存储过程。
3.引擎层（插件式）：负责数据的实际存储和提取。默认使用 InnoDB（支持事务、行锁），也支持 MyISAM 等。
4.存储层：操作系统文件系统，存放数据文件（.ibd）、日志文件（Binlog, Redo Log）和配置文件。
总结：客户端通过连接层进入，由服务层分析并优化 SQL，调用引擎层存取数据，最终落地到存储层的文件中。

03 数据库服务程序升级步骤方法（5.7-->8.0） mysql -uroot ##################################
备份数据 -> 停止旧服务 -> 部署新二进制文件 -> 修改配置 -> 启动新服务 -> 执行升级脚本

04 数据库服务查询语句执行原理 select#####################################################
1.连接器：校验身份与权限，建立会话。
2.分析器：词法/语法检查，将 SQL 转为语法树。
3.优化器（大脑）：最关键一步。基于成本模型（CBO），决定走哪个索引、表连接顺序及算法，生成最优执行计划。
4.执行器：按执行计划调用引擎接口，再次校验权限，开始“干活”。
5.存储引擎（手脚）：负责真实读写。先在内存（Buffer Pool）找，没有则读磁盘，利用 MVCC 保证并发一致性，将数据行返回。

```

```sh
步骤一：数据库部署环境准备 (Ubuntu 适配版)###################################################################

1.系统更新与基础工具安装
Ubuntu 不需要换源（除非默认源慢），但建议更新并安装必要工具（如 wget, vim, net-tools）。
	sudo apt update
	sudo apt install -y wget vim net-tools libaio1 libnuma1
	apt install -y libncurses5
#注意：MySQL 8.0 二进制包依赖 libaio1 和 libnuma1，必须安装，否则启动会报错


2.关闭防火墙 (Ubuntu 使用 ufw)
文档中的 firewalld 是 CentOS 的，Ubuntu 默认使用 ufw。
#停止防火墙
sudo ufw disable
#或者如果不想完全关闭，只开放 3306 端口
#sudo ufw allow 3306/tcp


3.关闭 AppArmor (可选，但推荐以避免权限干扰)
CentOS 关闭 SELinux，Ubuntu 对应的是 AppArmor。对于二进制安装，有时 AppArmor 会拦截非标准路径的访问。
#临时停止
sudo systemctl stop apparmor
#永久禁用 (防止重启后生效)
sudo systemctl disable apparmor
(注：如果你熟悉 AppArmor 配置，也可以不关闭，而是修改配置文件允许 MySQL 访问 /data/3306，但为了简化操作，测试环境建议先关闭)

4.检查并卸载已有数据库
Ubuntu 可能预装 mariadb 或 mysql-server (apt 版)。
#检查已安装的 mysql/mariadb 相关包
dpkg -l | grep -E 'mysql|mariadb'

#如果有，彻底卸载 (注意：这会删除 apt 安装的数据文件，请确认数据不重要)
sudo apt remove --purge -y mysql-server mysql-client mariadb-server
sudo apt autoremove -y


5.创建 MySQL 用户和组
文档中是在初始化前创建，这里提前做。
sudo groupadd mysql
sudo useradd -r -g mysql -s /bin/false mysql


步骤二：数据库程序下载安装 (二进制方式)######################################################################
1.下载并解压
cd /usr/local/
#上传文件 (Ubuntu 直接用 scp 从本地传，或者用 wget 下载)
#假设文件已在当前目录
sudo tar xf mysql-8.0.36-linux-glibc2.12-x86_64.tar.xz

#创建软连接
sudo ln -s mysql-8.0.36-linux-glibc2.12-x86_64 mysql

#修改所有者 (非常重要，Ubuntu 权限控制严格)
sudo chown -R mysql:mysql /usr/local/mysql

2.配置环境变量
编辑 /etc/profile (或者 ~/.bashrc)。
sudo vim /etc/profile

在末尾添加：
export PATH="$PATH:/usr/local/mysql/bin"

生效：
source /etc/profile
mysql -V  # 验证是否显示版本号


步骤三：数据库初始化操作###################################################################################
1.创建数据目录
sudo mkdir -p /data/3306/data
sudo chown -R mysql:mysql /data/3306/data

2.检查配置文件
确保 /etc/my.cnf 不存在，或者备份它，以免干扰初始化。
cat /etc/my.cnf

执行初始化 (不安全模式，免密)
sudo /usr/local/mysql/bin/mysqld --initialize-insecure --user=mysql --datadir=/data/3306/data --basedir=/usr/local/mysql
观察输出，只要没有 [ERROR] 即为成功。


步骤四：编辑数据库服务配置文件##############################################################################
创建 /etc/my.cnf，内容与文档一致。
sudo cat > /etc/my.cnf << EOF
[mysqld]
port=3306
user=mysql
datadir=/data/3306/data
basedir=/usr/local/mysql
socket=/tmp/mysql.sock
log-error=/data/3306/data/mysql.err
pid-file=/data/3306/data/mysqld.pid
EOF


步骤五：启动运行数据库服务 (关键差异点)######################################################################
创建 /etc/systemd/system/mysqld.service 文件：

sudo vim /etc/systemd/system/mysqld.service

写入以下内容（这是之前成功的“万能”模板，针对 Ubuntu 微调）：
[Unit]
Description=MySQL Database Server
After=network.target syslog.target

[Service]
Type=simple
User=mysql
Group=mysql
LimitNOFILE=65535
WorkingDirectory=/data/3306/data
ExecStart=/usr/local/mysql/bin/mysqld --user=mysql
Restart=on-failure
TimeoutStartSec=900

[Install]
WantedBy=multi-user.target

启动步骤：
#1.重载配置
sudo systemctl daemon-reload

#2.启动服务
sudo systemctl start mysqld

#3.查看状态
sudo systemctl status mysqld

#4.设置开机自启
sudo systemctl enable mysqld


步骤六：验证与后续操作#####################################################################################

1.检查端口
sudo netstat -ntulp | grep 3306
或者
sudo ss -ntulp | grep 3306

2.登录数据库
mysql -u root

3.设置密码 (进入 MySQL 后)
-- 修改密码
ALTER USER 'root'@'localhost' IDENTIFIED BY '123456';
FLUSH PRIVILEGES;
EXIT;

4.测试远程连接 (如果需要)
Ubuntu 的防火墙如果没关，记得开放 3306。如果在云服务器（如阿里云/腾讯云/AWS），还需要在安全组中放行 3306 端口。
-- 创建远程用户
CREATE USER 'root'@'%' IDENTIFIED BY '123456';
GRANT ALL PRIVILEGES ON. TO 'root'@'%' WITH GRANT OPTION;
FLUSH PRIVILEGES;
```
