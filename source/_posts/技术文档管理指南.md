# 技术文档管理指南

## 📚 概述

本博客已配置为 Markdown 笔记归纳系统，所有文章都归类到"技术文档"中。

## 🏷️ 分类和标签系统

### 分类（Categories）
用于大类别的划分，例如：
- 前端开发
- 后端开发
- 数据库
- DevOps
- 算法与数据结构
- 工具使用

### 标签（Tags）
用于更细粒度的标记，例如：
- JavaScript
- Python
- Docker
- Git
- Vue.js
- React

## 📝 创建新文档

### 方法一：命令行创建

```bash
hexo new "文档标题"
```

### 方法二：手动创建

在 `source/_posts/` 目录下创建新的 `.md` 文件。

## 📋 文档模板

````
---
title: 文档标题
date: 2026-04-29 12:00:00
categories:
  - 技术文档
  - 子分类（可选）
tags:
  - 标签1
  - 标签2
---

这里是文档内容...
```

## 🔍 查看文档

- **技术文档列表**：访问 `/archives/` 查看所有文档
- **按分类浏览**：访问 `/categories/` 查看分类
- **按标签浏览**：访问 `/tags/` 查看标签云

## 💡 最佳实践

1. **每个文档都要有分类**：至少包含"技术文档"这个主分类
2. **添加相关标签**：方便搜索和关联
3. **使用清晰的标题**：让人一眼就能看出文档内容
4. **添加目录**：长文档建议使用 TOC
5. **代码块标注语言**：使用 ```javascript 等标注代码类型

## 🚀 部署更新

每次添加或修改文档后，执行：

```bash
.\deploy.bat
```

或手动执行：

```bash
hexo clean && hexo generate && hexo deploy
```
